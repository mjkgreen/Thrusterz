# Fonts

Bundled with the game so it renders the same offline and inside an app
wrapper (no request to Google Fonts at runtime).

| Font | Use | License |
| --- | --- | --- |
| Exo 2 | headings and UI | SIL Open Font License 1.1 ([OFL-Exo2.txt](OFL-Exo2.txt)) |
| JetBrains Mono | HUD numbers and labels | SIL Open Font License 1.1 ([OFL-JetBrainsMono.txt](OFL-JetBrainsMono.txt)) |

Subsets: Latin and Latin Extended for both, plus Greek for JetBrains Mono
(the Δ in the HUD). Variable-weight files from Google Fonts; `fonts.css`
maps them to the weights the game uses.
